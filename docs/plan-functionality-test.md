# 自動テストの計画書
- 確認のポイント: 「コード上で動いていること」と「ユーザーが実際に操作して可能なこと」を区別し、後者を優勢する
- 可能な限りオフラインで完結できるように頑張る

# Phase 1
## 基本機能
- 挿入されたボタンから起動
- 閉じるボタンを押して閉じる
- 再生・一時停止
- 次の動画
- 前の動画
- リピート再生
- A-Bリピート
- 再生速度変更
- 音量調整・ミュート
- シークで任意の時間に飛ぶ
- 時間位置バーが動いているか
- ヒートマップが正しいか
- コメントプレビュー
- 時間表示
- コメント表示・非表示切り替え
- 全画面表示

# Phase 2
## 設定
- 画質を変えて動画の画質が実際に追従することを確認
- GitHubに飛べるか
- 再読み込みボタン
- コメント付き画像保存の動作
- 公式視聴ページボタンで公式視聴ページに飛べるか
（めんどくさいので書かないが、設定パネルの網羅的・徹底的・神経質な動作確認）

# Phase 3
## 詳細
- 投稿動画一覧をプレイリストで開くボタンの動作確認
- プロフィール画像クリックの動作確認
- ニコニコ市場ボタンは廃止されたので削除
- 関連動画のマイリスト追加
- とりあえずマイリスト追加の動作確認
- 動画情報ボタンの動作確認
- 動画クリックで実際に飛べるか
- 自動スクロールのオン・オフ
- コメント時間指定の動作確認
- メニューの開閉
- メニューの各項目の動作確認
- リロードボタン動作確認
- 連続再生ボタン
- リピートボタン
- 並び替えボタン

# Phase 4
## その他
- タグ編集ボタンでタグ編集モードに入れるかどうか
- タグ編集で書き換えが実際に動作するかどうか
- タグ更新ボタンが実際に動作するかどうか
- 大百科に項目があるにも関わらアイコンが「？」になっていないかどうか
- ログインしていませんの表示とログイン状態を区別できるか
- コメント投稿フォームのログイン状態と非ログイン状態の区別
- 実際にコメント投稿フォームでコメントが投稿できるか
- 投稿したコメントがサーバーに反映されているか
- 投稿したコメントは投稿操作1回で済むかどうか
